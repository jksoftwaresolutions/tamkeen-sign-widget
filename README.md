# تمكين — إضافة لغة الإشارة وأدوات الوصول

1. فكّ ضغط الحزمة وارفع مجلد `balagh` كاملاً إلى المسار العام في السيرفر. أبقِ الملفات ومجلد `videos` داخل المجلد نفسه.
2. افتح `/balagh/demo.html` عبر رابط الموقع لتجربة الإضافة.
3. ضع السطر الآتي مرة واحدة في القالب المشترك للموقع قبل `</body>`. في WordPress يمكن وضعه في تذييل القالب أو من خلال أداة تسمح بإضافة وسوم HTML في التذييل.

```html
<script type="module" src="/balagh/widget.js"></script>
```

للاستضافة المركزية، استبدل المسار بعنوان HTTPS الكامل لملف `widget.js` على سيرفر الإضافة. عند اختلاف النطاق، اضبط ترويسة `Access-Control-Allow-Origin` لملف JavaScript و`manifest.json` للسماح بنطاقات المواقع المدمجة. إذا كان الموقع يستخدم سياسة أمان المحتوى (CSP)، راعِ تحميل السكربت والفهرس والمقاطع، والسماح بأنماط التصميم المضمّنة في الواجهة.

قدّم ملفات JavaScript بنوع `text/javascript` أو `application/javascript`، وملف الفهرس بنوع `application/json`، والمقاطع بنوع `video/mp4`. ادعم طلبات النطاق الجزئي للمقاطع (`Range`) ليعمل التنقل داخل الفيديو. تحتاج الإضافة إلى استضافة ملفات ثابتة ومتصفح حديث يدعم JavaScript modules وShadow DOM. افتح صفحة التجربة عبر HTTP أو HTTPS.

## الاستخدام

- افتح الأيقونة الخضراء أسفل اليسار ثم «مكتبة المقاطع». تضم المكتبة 297 مقطعًا، وكل فيديو يُطلب عند تشغيله.
- ظلّل نصًا في الصفحة واضغط الأيقونة التي تظهر قربه لتبدأ الترجمة تلقائيًا. تشغّل الإضافة مقطع العبارة أو الكلمة إن توفر، وتهجّي الكلمات الأخرى تلقائيًا بحروفها. تظهر الحروف أو الرموز التي لا تملك مقطعًا، ويتابع المشغّل بقية النص.
- يعرض المشغّل الفيديو بأبعاده الأصلية ويدعم ملء الشاشة عبر زر ⛶. يجهّز جميع المقاطع المطلوبة للنص قبل بدء التشغيل، ويحمّل كل ملف مكرر مرة واحدة. تظهر حالة التجهيز في البداية، ثم تعمل المقاطع من ذاكرة المتصفح. يستخدم تداخلًا بصريًا مدته 90 ميلي ثانية وتغبيشًا خفيفًا بقوة 1.5 بكسل عند الانتقال، مع استمرار حركة الفيديو. تُختصر الحركة عند تفعيل تقليل الحركة في الجهاز.
- تشغّل «مسارات الإشارة» المقاطع المتاحة لخطوات المسار وتوضح عدد الخطوات التي ينقصها مقطع. زر النجمة يحفظ المسار في المتصفح.
- تتضمن «أدوات الوصول الشامل» التحكم بالحجم والتباين والتباعد وإخفاء الصور والمؤشر والتدرج الرمادي وإعادة الضبط. تتوفر قراءة النص أو الصفحة بحسب الأصوات التي يدعمها المتصفح.

## ربط المسارات بخدمات الموقع

لربط زر الانتقال إلى الخدمة في تفاصيل المسار، أضف وسم `meta` بالمسار الفعلي في رأس الصفحة.

```html
<meta name="balagh-path-cases" content="/services/cases">
```

معرّفات المسارات هي `cases` و`schedule` و`file` و`request` و`verdict` و`virtual`. تعمل المقاطع وحفظ المسارات من دون هذه الروابط.
